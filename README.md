DayBook is a premium, developer-focused daily planner built with a sleek, minimalist aesthetic. It replaces traditional endless to-do lists with a **daily capacity model**, helping you stay focused on what you can actually achieve today without feeling overwhelmed. 

If you like this project, please consider giving it a ⭐️ to show your support!

## 🚀 Features

- 🌓 **Premium Themes:** Seamlessly switch between a stunning dark "silk" aesthetic and a crisp, warm light mode.
- ⏱️ **Capacity Tracking:** Set your daily work minutes and watch the progress bar fill up as you plan your tasks.
- 🔄 **Smart Rollover:** Unfinished tasks automatically carry over to the next day. If a task rolls over more than 3 times, DayBook nudges you to either drop it or split it up.
- 📅 **Recurring Tasks:** Effortlessly set up daily repeating tasks (like "Leetcode") until a specific date.
- ✉️ **Morning Digest:** Get an automated email summary of your planned tasks for the day (powered by Resend).
- ⚡ **Lightning Fast UI:** Built with React, Vite, and Tailwind CSS for a snappy, app-like experience.

## 🛠️ Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, Day.js
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **Auth:** JWT (JSON Web Tokens)
- **Emails:** Resend API

## 🏃‍♂️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+) and [MongoDB](https://www.mongodb.com/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ankitrmishra01/DayBook.git
   cd DayBook
   ```

2. **Setup the Backend**
   ```bash
   cd backend
   npm install
   # Create a .env file based on .env.example
   npm run dev
   ```

3. **Setup the Frontend**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```

4. **Open the App**
   Visit `http://localhost:5173` in your browser.
